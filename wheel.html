Evidence and submission readiness

Wheel-210 is evaluated as a separate algorithm category, algorithm=wheel, with a proposed faithful=yes,bits=1 classification pending upstream review. The implementation is being independently packaged and checked before any submission. The reported CPU, compiler version and throughput have not been reproduced in the public CI; the private source is not published here. Competing implementations measured on other CPU models cannot establish wins or a common leaderboard ranking. The official competition requires a reproducible Dockerfile, documented source, correct sieve output and a pull request against drag-race.

Separate tracks: Base CI results · Upstream rules and competition · Official PrimeView. Reported measurements should not be mistaken for official rankings.
