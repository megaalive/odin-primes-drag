Reading these results

Each lane is timed independently; passes/s = completed sieve passes ÷ elapsed seconds. The packed-bit paths use the competition's algorithm=base, faithful=yes, bits=1 protocol; the separate byte-storage paths use bits=8. The program verifies the known prime count (78,498 at one million) outside the measurement window. GitHub-hosted runners can change CPU type and available resources between jobs; compare competitors only when tested on the same runner under a controlled protocol. No cross-CPU aggregate or inferred speedup is shown.

Source and raw evidence: GitHub repository. Benchmark reporting is informational and independent of the official PrimeView leaderboard.
