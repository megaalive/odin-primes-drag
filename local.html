Each implementation used its original sieve kernel and the same compiler flags. Single-thread results come from six confirmation blocks. The 20-thread results come from seven rotating-order blocks, each measured using a shared five-second window and 20 threads in one process. The Wheel-30 20-thread measurements used a separate research runner; its public CI entry still runs one thread.

Read each chart independently: the timing protocols differ between single and multi-thread, so these numbers are not a scaling-efficiency calculation. Temperature, package power and throttling indicators were unavailable; Windows background activity and hybrid-core scheduling remain possible sources of variation.
